# Estructuras de Datos 

Repositorio académico con las implementaciones, ejercicios y evaluaciones desarrolladas para la asignatura **Estructuras de Datos** en la Escuela Superior Politécnica del Litoral (ESPOL). El código está desarrollado en **Java** aplicando programación orientada a objetos, tipos de datos abstractos (TDA) y análisis de eficiencia computacional.

---

## Estructura del Repositorio

```text
EDD/
├── Practica/   # Implementaciones base de TDAs y ejercicios de preparación para exámenes
├── Talleres/   # Resoluciones de actividades prácticas desarrolladas en clase
└── Tareas/     # Entregables autónomos de implementación y resolución de problemas
